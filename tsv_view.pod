=head1 NAME

tsv_view -- tiny utility for viewing TSV files

=head1 SYNOPSIS

B<tsv_view> I<[options]> I<[files...]>

=head1 OPTIONS

=over 6

=item B<-h> or B<--help>

Display this screen.

=item B<-l>

Replace \n with LF.

=item B<-H>

Consider first line as a header.

=back

=head1 EXAMPLE

Original file.

    $ cat bench.tsv 
    Implementation        Language        Type        Time
    luajit         Lua        JIT        3.42
    lua         Lua        Interpreter        28.91
    gforth        Forth        Interpreter        12.43
    $

We can view it as the following.

    $ tsv_view -H bench.tsv
    Implementation: luajit 
    Language      : Lua
    Type          : JIT
    Time          : 3.42
    
    Implementation: lua 
    Language      : Lua
    Type          : Interpreter
    Time          : 28.91
    
    Implementation: gforth <
    Language      : Forth
    Type          : Interpreter
    Time          : 12.43
    
    $
